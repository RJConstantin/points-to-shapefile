Point Data Utility

Points to Shapefile

Turn an Excel table, CSV or copied and pasted point list into a point shapefile. Choose the coordinate columns, define the coordinate system, select the attributes to keep and name the output file.

Files are processed in your browser and are not uploaded to a server.

1. Add point data

Use an Excel or CSV file or paste rows copied directly from Excel or another table.

No point data loaded.
Not sure which coordinate system to choose?

First, look at the coordinate numbers.

Looks like: -113.5, 56.7 These are longitude / latitude values. Select WGS 84 latitude / longitude or NAD 1983 latitude / longitude based on the source.
Looks like: 473566, 6362909 These are metre-based coordinates. If the source says UTM, use the Alberta map below.

Simplified guide, not to scale. The 114°W line separates UTM Zone 11N and UTM Zone 12N.

If your site is on the west side of Alberta
Examples: Calgary, Slave Lake, Grande Prairie, Hinton, Jasper
Select NAD 1983 UTM Zone 11N.

If your site is on the east side of Alberta
Examples: Edmonton, Fort McMurray, Fort McKay, Cold Lake
Select NAD 1983 UTM Zone 12N.

Use the source name when it is provided.
If it specifically says 10TM / AEP Forest, select NAD 1983 10TM AEP Forest. If it says 3TM, select the matching 3TM option instead of using the UTM map.

2. Set the coordinate fields

Select which columns contain X and Y. For projected systems, X is Easting and Y is Northing. For latitude / longitude, X is Longitude and Y is Latitude.

Fields to keep

All fields are kept by default. Shapefile attribute names are limited to 10 characters so longer names will be shortened in the DBF.

3. Create the shapefile

The download is a ZIP containing the shapefile components, including the projection file.

Ready to export
Choose the coordinate fields and coordinate system before exporting.
